# 📂 About This Repository

Welcome to my **OIBSIP Cyber Security Analyst Internship Repository**.

This repository documents my practical work, research, security investigations, configuration tasks, and technical learning throughout the internship.

The purpose of this repository is not only to submit completed tasks, but also to demonstrate my ability to:

- 🔎 Perform network reconnaissance and security scanning
- 🌐 Identify exposed services and potential attack surfaces
- 🛡️ Configure and troubleshoot host-based security controls
- 📊 Capture and analyze network traffic
- 🚨 Understand common cybersecurity threats
- 📝 Document vulnerabilities and security findings
- 🧠 Research security concepts and translate them into practical knowledge
- 📚 Develop SOC Analyst and Blue Team fundamentals

> **Note:** All security testing documented in this repository is performed in controlled lab environments and is intended for educational purposes.

# 🎯 Internship Objectives

Throughout this internship, my main objectives are to strengthen my practical understanding of:

### 🔍 Reconnaissance
Understanding how attackers discover systems, services, ports, and technologies exposed on a network.

### 🛡️ Defensive Security
Learning how firewalls and system configurations can reduce attack surfaces and restrict unauthorized access.

### 📡 Network Analysis
Understanding how network traffic can be captured and analyzed to identify suspicious or unusual activity.

### 🐛 Vulnerability Assessment
Learning how vulnerability scanners can identify potentially insecure configurations and outdated services.

### 🚨 Threat Intelligence
Developing knowledge of common cyber threats, attack techniques, indicators of compromise, and potential mitigation strategies.

### 📝 Security Reporting
Learning how to document findings clearly so that technical and non-technical stakeholders can understand the associated risks.
